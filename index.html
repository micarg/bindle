Οδηγός γραμμής

Φωτίζει τη γραμμή που διαβάζεις και αχνίζει τις υπόλοιπες. Πάτα δεξιά για την επόμενη γραμμή, αριστερά για την προηγούμενη. Για αλλαγή σελίδας σύρε το δάχτυλο.

Η οθόνη μένει ανοιχτή

Η οθόνη δεν σβήνει όσο διαβάζεις. Με 5′ ή 15′ σβήνει μόνο αν περάσει τόσος χρόνος χωρίς να γυρίσεις σελίδα, για να μη χαλάει μπαταρία αν το ξεχάσεις.

Μουσική ενώ διαβάζεις
Κλειδί Claude API (για τις περιλήψεις)

Το κλειδί το φτιάχνεις στο console.anthropic.com → API Keys. Μένει μόνο σε αυτό το κινητό και χρησιμοποιείται μόνο για τις περιλήψεις.

Αντίγραφο ασφαλείας

Κρατά την πρόοδο, τους σελιδοδείκτες, τις υπογραμμίσεις, τις περιλήψεις, τα στατιστικά και τις ρυθμίσεις. Τα ίδια τα βιβλία δεν μπαίνουν: σε νέο κινητό τα ξαναπροσθέτεις και η πρόοδός τους επανέρχεται.

Πάτα δεξιά για την επόμενη σελίδα, αριστερά για την προηγούμενη και στη μέση για το μενού. Κράτα πατημένη μια λέξη για ορισμό, υπογράμμιση ή σημείωση. Πάτα την ένδειξη κάτω αριστερά για να δεις σελίδες ή χρόνο που απομένει.

Πάτα «Διαγραφή» στο βιβλίο που θέλεις να σβήσεις.
